# 风格 DNA（小鹿版）

## 一句话

油画棒、肌理、马卡龙、留白、温暖、治愈、奶呼呼、结构清楚但不说明书。

像一个爱穿搭爱记录的人，用油画棒在纸上随手画出来的一张温柔解释图。

## 必须

- 16:9 横版正文配图。
- 浅奶油/浅奶茶色背景：柔和、干净、无花纹、无渐变、无杂物。
- 油画棒 / 蜡笔手绘质感：颗粒笔触、纸面纹理可见、蜡质颜料堆积感，涂色可略出界。
- 低饱和马卡龙配色：浅暖棕、雾紫、雾粉、奶黄，禁止高饱和/荧光色。
- 无立体厚重光影：平涂为主，禁止体积光、厚投影、3D 渲染、喷枪渐变。
- 大量留白：主体占画面约 40%-60%，至少 35% 空白。
- 少量中文手写批注：最多 5-8 处，每处 2-8 个字，颜色柔和不要黑色粗体。
- 一张图只讲一个核心动作、结构、状态或隐喻。
- 结构要自然表达，不要在图上写结构类型名称。

## 颜色

- 浅暖棕：小鹿身体、主体物件底色。
- 雾粉：重点批注、情绪点、关键提醒、结果（呼应腮红/蝴蝶结/蕾丝）。
- 雾紫：次要说明、系统状态、第二层解释（呼应睡帽/睡衣）。
- 奶黄：主流程、路径、箭头、高亮点（呼应弯月抱枕）。

颜色要克制，宁可少不要多。

## 绝对不要

- 不要商业插画、PPT 信息图、正式流程图、课程课件。
- 不要 flash 贴纸感、精致扁平矢量插画。
- 不要写实毛发、3D 渲染、金属高光。
- 不要复杂背景、渐变、阴影、噪点。
- 不要科技感 UI、真实 App 截图。
- 不要把每个节点都解释清楚。
- 不要左上角写"Workflow 流程图 / 系统架构图 / 常见坑"等类型标题。

## 审美方向

要温暖、治愈、有创意、简洁清爽、奶呼呼但认真。

不要幼齿化、不要很复杂、不要死板、不要纯卖萌。
