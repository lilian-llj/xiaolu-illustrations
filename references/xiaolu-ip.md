# 小鹿 IP 规范（v1.0 定稿 2026-07-25）

## ⭐ 官方标准像（最重要）

- 文件：`assets/小鹿-标准像-v1.png`（用户亲自确认版）
- 原始参考图：`assets/小鹿-ref.png`
- **铁律**：生成任何出现小鹿的图，一律用标准像垫图（`--ref-image`），不要用纯文字 prompt 裸生角色。文字压不住细节，垫图才稳（多轮实测结论）。

## 1. 视觉形象

### 主体
- **幼年梅花小鹿**：体型短幼、四肢短小、大头短身，整体奶呼呼、软乎乎的幼年体。绝不能是成年鹿比例。
- 身体浅暖棕色，背部/身侧有稀疏柔和的白色梅花斑点。
- 两根短小圆润的幼年鹿角（不写实分叉）。
- 不露出尾巴。

### 面部
- **圆黑豆豆眼**：纯黑圆点，无高光、无反光、无眼白。
- **爱心腮红**：粉色心形腮红，标志性特征。
- **鼻梁三点白**：3 个白色小圆点在鼻梁上（鼻子正上方、两眼之间），**绝对不在额头**；额头保持棕色，全脸白点总数不超过 3 个。
- 眼周和嘴部为白色斑块；黑色小圆鼻 + 极细微笑线。
- 面部线条流畅圆润，不用抖动线条破坏脸部。

### 配饰（必须保留）
- 双鹿角根部各系 1 个粉色蝴蝶结。
- 紫底白星星睡帽（雾紫色 + 白色手绘小星星 + 帽尖白绒球）。
- 雾紫色连体睡衣/睡裙，领口和下摆均有粉色蕾丝包边。

### 道具
- 淡黄色弯月抱枕：**标准像必带；场景图可选**。小鹿需要腾出手做动作时直接省略，让双手参与动作。

## 2. 性格气质

- 温和、认真、有点迷糊，做事慢半拍但坚持到底。
- 不是卖萌吉祥物，而是内容的"陪伴者"——和主题一起行动、搬运、整理、尝试。
- 眼神呆萌但专注，动作笨拙却真诚。

## 3. 在配图中的职责

小鹿必须参与核心动作，不能只当装饰：
整理衣服、打卡打勾、搬运单品、比对搭配、在日历上做标记、抱着数据卡片、搭桥牵线、分拣、汇聚、压榨想法、看内容发酵。

判定标准：去掉小鹿画面仍成立 = 小鹿太"装饰"，需重写构图。

## 4. 禁止事项

- 不要纯商业吉祥物/贴纸感、flash 贴图感。
- 不要复杂服装、写实毛发、3D 渲染、金属高光。
- 不要成年鹿比例。
- 不要给眼睛加高光、反光、眼白。
- 不要露出尾巴。
- 不要额头白点（Seedream 顽固先验，prompt 里要显式压制）。
- 不要复杂背景；场景图保持干净留白。

## 5. 已知生成陷阱（实测积累）

| 陷阱 | 表现 | 对策 |
|---|---|---|
| 额头白点 | 三点白跑到额头/眉心 | prompt 显式写"额头必须纯棕色、绝对不能有白点"；仍出错就重跑或 PIL 抹掉 |
| 尾巴 | 屁股后冒小尾巴 | prompt 显式写"绝对不能画出尾巴" |
| 睡衣分体 | 变成上衣+裤子 | 写"连体睡衣裙（像连衣裙，不是上下两件套）" |
| 眼睛加高光 | 变闪亮萌眼 | 写"纯黑无高光无反光无眼白" |
| 鹿角变大 | 画成成年鹿角 | 写"短小圆润的幼年鹿角" |
